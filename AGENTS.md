# AGENTS.md

## Logbooks and experiments

`.agents/logbooks/` records findings and decisions per module (data mixing,
training, evaluation). Read the relevant logbook before changing a module, and add a dated
entry (newest on top) when a run or a fix teaches something. Format and index:
`.agents/logbooks/README.md`.

`.agents/experiments/` has one file per training experiment (goal, setup,
links, results, next steps) and a comparison table. Format:
`.agents/experiments/README.md`.
